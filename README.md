# flyme2.5
FlyMe2TheMoon remake project in Godot. Vibecoded by Gemini 3.5 Flash. Supervised and tested manually by a human.

## Current status: around 40%

What works:
- Initial game boot (directly to level 1)
- All level implemented, playable

What don't:
- Proper control (can control but not so convenient/matching to the old game)
- Story audio and text
- A working menu, settings, as well as progress save
- Level layout matching those of the original game
- Anything you would expect in a complete game; this is very much a PoC now

## Download and play
Install Godot (Steam, or latest GitHub build). Clone the repo.

### Get the data
The game is free on App Store for very old phones (the ones that can run 32-bit apps); you can dump the IPA file, and decrypt it. Then, follow [this guide](https://github.com/imchocomint/flyme2.5/blob/main/game_data/README.md).

Or you can just download a decrypted IPA from the internet. I mean, who cares?

### Play
Load the /project/project.godot in Godot. Press F5/click the small triangle button the upper right to play.
